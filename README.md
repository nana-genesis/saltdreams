### Características Principais

- **Design imersivo**: Cenário praiano com animações suaves (céu gradiente, sol pulsante, ondas em movimento, nuvens flutuantes)
- **Formulário completo**: Campos para nome, e-mail e telefone com validação robusta
- **Segurança**: 
  - Rate limiting (3 tentativas a cada 2 minutos)
  - Sanitização de dados contra XSS
  - Logs estruturados sem exposição de dados sensíveis
  - Proteção contra envios duplicados
- **Experiência do usuário**: 
  - Feedback visual em tempo real
  - Mensagens de erro amigáveis
  - Animações sutis e responsivas
  - Design totalmente responsivo (mobile-first)

## Tecnologias utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Animações personalizadas, gradientes, efeitos de vidro (backdrop-filter)
- **Bootstrap 5.3**: Framework CSS para componentes e grid responsivo
- **Bootstrap Icons**: Iconografia elegante
- **JavaScript**: 
  - Validação de formulário
  - Sistema de rate limiting
  - Logs estruturados
  - Manipulação DOM
  - Simulação de envio assíncrono
